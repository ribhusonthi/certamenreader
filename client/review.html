Design review · pre-merge · round 3

New identity, and two front doors

Certamen Reader takes on the visual direction from the Figma design proposal, and the home page splits in two: a landing page for visitors, a dashboard for people who are signed in.

Read first
This round reverses two decisions from round 2. The verdigris accent is now violet, and EB Garamond and Libre Franklin are gone. That is deliberate — we adopted the Figma proposal's palette and type wholesale. Everything else round 2 established, including the accessibility floor, still stands. This page is set in the new typefaces, so the type below is the real thing rather than a description of it.

What changed

Six things, in rough order of how much of the site they touch.

Identity
A violet accent and a four-family type system, taken from the Figma proposal. These are design tokens, so the change lands on all 45 pages at once, not just the new ones.
Two home pages
Visitors now get a landing page explaining what certamen is; signed-in users get a dashboard. Previously both saw the same page, where every personal panel sat empty for a guest.
Dashboard
New. Stat tiles with sparklines, a per-category accuracy breakdown, recent activity and a leaderboard preview — all reading real endpoints, not mock data.
Landing
New. The hero runs a live reader demo: a real question streams word by word at 340 wpm with the celerity bar filling, because that is the one thing about this product a screenshot cannot show.
Wordmark
Now set in Fraunces 700. It was the reading serif at weight 500, which read as running text rather than a mark.
Demo data
A seed script fills a local database with 125 tossups, 125 bonuses and 927 buzzes, so the site can be demonstrated without production credentials.

One thing worth knowing about the fonts

Our first pass at the type looked wrong and it took a while to see why: the font request was missing Fraunces 700 entirely, so the browser was synthetically emboldening 600 — which smears the stroke contrast that makes Fraunces worth using. DM Sans was also missing its optical-size axis. The four requests are now byte-identical to the proposal's own stylesheet.

Fixes along the way

Database
The search bar's outline was on the input, not the group — so the left edge showed a border and the right showed none, because the buttons' border was the same colour as their own fill. The outline now sits on the container.
Home page
The account lookup does an unguarded fetch. With the dashboard code below it in the same module, one auth hiccup would have blanked the entire page. Now wrapped.
Categories
The codebase carries two spellings — History and Roman History, Literature and Latin Literature — depending on whether you ask constants.js or the parser. The dashboard now accepts either. The inconsistency itself predates this work and is still open.

Running it locally

No production credentials needed. The seed script refuses to run against anything that isn't localhost.

brew services start mongodb-community
npm run seed:demo
npm start                                  # dashboard, signed in
LOCAL_DEV_BYPASS_AUTH=false PORT=3001 npm start   # landing, signed out

One gotcha: set DEV_USERNAME to something without an @ in it. The leaderboard deliberately hides accounts that still have an email-shaped username, so local@dev silently drops off it and the performance-points tile reads “unranked”.

Known gaps

Things worth hearing from us rather than finding yourselves.

  • Open No screenshots in this round. The round 2 shots showed the verdigris design and would now actively mislead, so they have been removed rather than left to rot. New captures need to be taken by hand.
  • Open Two invented numbers on the landing page. The design shows “10,100+ questions” and “840 active players”. Those are Figma's placeholders and there is no unauthenticated endpoint behind them, so they render as em-dashes. Tournaments is real. We need either a public counts endpoint or a decision to drop the other two — they are public claims about the product.
  • Open The admin console and API docs were never designed. Roughly 20 pages of API documentation plus the whole admin section are absent from the Figma proposal. They currently inherit the new tokens and nothing else.
  • Check The landing headline weight is inferred. Figma's Landing.tsx was missing from the export, so the headline is built from a screenshot. Everything else comes from files we could read.
  • Check Violet on a projector. Team rooms get shown on shared screens. Someone should look at the scoreboard and the category chips on real projector hardware before a tournament.
  • Note Round 2's open items are still open — four pages not yet on the shared component layer, the reader still has no page heading, and set-name grouping still assumes a naming pattern.
