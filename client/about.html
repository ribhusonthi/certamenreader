About

About Certamen Reader

A text-based Certamen packet reader created by Ribhu Sonthi. The reader was adapted from Geoffrey Wu's QB Reader. Packets are collected from certamenlibrary.org (awesome website with a lot of certamen packets) and parsed into JSON using a Python-based Certamen packet parser. UI was designed by Jeremiah Raj.

About Privacy policy

Why I built this

In highschool, our Certamen team wanted an online practice tool to practice whenever we could. We saw that QBReader was opensource, so we got the code and adapted it to play Certamen questions.

Initially, it was very hard to actually parse Certamen questions since there is not a unified format as it is with Quizbowl, so we had to manually go through and parse questions.

Now, I am using Gemini to go through questions to see if the question is parsed right and to catch any typos made while writing questions.
